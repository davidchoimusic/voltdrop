🔥 Canadian Ampacity & Derating Check

Apply the Canadian ambient and conductor-count factors, then see which CEC safety limit controls.

Canadian source: CSA C22.1:24 — Canadian Electrical Code, Part I, 26th edition (2024). This calculator uses Tables 2/4, 5A, and 5C and Rules 4-004, 4-006, 8-104, and 14-104. Provincial adoption and amendments vary; confirm the edition adopted locally.

AWG = American Wire Gauge. It is printed on the wire jacket.

Use the conductor insulation rating for the starting column. THHN is normally 90°C. This is not the termination temperature rating.

Marked equipment: use its marked termination temperature. Unmarked equipment: use 60°C when rated not more than 100 A or marked for #1 AWG and smaller; use 75°C above that. Rule 4-006 applies to the first 1.2 m and permits a transition beyond it. VoltDrop conservatively applies the lower limit throughout as a simplified method.

°C

CEC Table 5A lists single ambient points only above 30°C. At or below 30°C the factor is 1.00, with no cool-ambient credit. Between listed points, this calculator uses the next higher row; it never interpolates or rounds down.

conductors

Count insulated power and lighting conductors. A bonding conductor never counts. Do not count control or signal conductors, or a neutral carrying only unbalanced current in a normally balanced circuit. Count a neutral carrying current comparable to the phase conductors or significant harmonic current from non-linear loads. The Code is silent on spares; VoltDrop counts installed power or lighting spares by default as a conservative reading, not a Code quotation. Your local authority may differ.

A

CEC Rule 8-104 limits a continuous load to 80% of corrected ampacity for standard 80%-rated equipment. This is a separate check, not a derating multiplier.

What this checks

This Canadian edition uses CSA C22.1:24 Tables 2/4 base ampacities, Table 5A ambient factors, Table 5C conductor factors, Rule 4-004 counting, a conservative simplified Rule 4-006 termination check, Rule 14-104 small-conductor caps, and a separate Rule 8-104 continuous-load check.

Ampacity and voltage drop are separate checks — a wire must pass both.
