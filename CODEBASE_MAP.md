## Directory Structure
```
/ (root = the static site)
  index.html            — single source of page chrome (header/sidebar/footer) + voltage drop calculator
  styles.css            — ALL theme tokens + styles; power-tool dark theme; mobile/desktop header blocks
  common.js             — shared chrome: US/CA country state (localStorage), header chip, mobile Tools menu
  app.js                — voltage drop calculator: 3 modes (drop/size/length), WIRE_TABLE, K-factor math
  ampacity.js           — Ampacity Check tool (NEC 310.16 + 240.4(D) caps)
  conduit.js            — Conduit Fill tool (NEC Ch9 Tables 4+5, THHN, EMT/PVC Sch40)
  boxfill.js            — Box Fill tool (NEC 314.16 volumes + counting rules)
  power.js              — Power Calculator (V/A/W solver, kW/kVA, PF, DC/1φ/3φ)
  build.mjs             — BUILD SCRIPT: cache-bust hashes + generates all subpage dirs from index.html
  verify.mjs            — Playwright e2e suite: 28 hand-computed assertions; BASE env for live runs
  partials/ (6 .html)   — per-tool <main> bodies spliced into index.html chrome by build.mjs
  img/                  — logo.png, favicon.png, apple-touch-icon.png, og.png
  wire-size-calculator/ | max-wire-length/ | ampacity-check/ | conduit-fill/
  box-fill/ | power-calculator/ | privacy/ | terms/   — GENERATED by build.mjs (committed)
  sitemap.xml, robots.txt

comments-app/ (Next.js 16 + NextAuth + Prisma/Postgres, basePath /comments)
  app/CommentsClient.tsx — the feedback UI: sign-in, privacy name picker, post/reply/edit/delete
  app/layout.tsx         — page chrome (brand header, back button); providers.tsx wraps SessionProvider
  app/api/feedback/      — GET list + POST create; [id]/ DELETE (admin) + PATCH (owner/admin edit)
  app/api/auth/[...nextauth]/ — NextAuth handler (Google + Facebook)
  lib/auth.ts            — authOptions: providers, Prisma adapter, ADMIN_EMAILS session flag
  lib/link-blocking.ts   — containsLink() spam filter (shared by POST + PATCH)
  prisma/schema.prisma   — User/Account/Session/VerificationToken + Feedback (replies, isHidden)
  Dockerfile             — standalone build, slim prisma CLI, `migrate deploy` on start
```

## Entry Points
- `index.html` → the site (every other page is generated from it by `node build.mjs`)
- `node build.mjs` → REQUIRED after editing index.html/styles.css/any .js; stamps ?v=<hash> + rebuilds subpages
- `python3 -m http.server 8642` + `node verify.mjs` → local test run (BASE=https://www.voltdrop.app/ for live)
- `comments-app/`: Coolify Dockerfile build; server starts via `prisma migrate deploy && node server.js`

## Key Definitions
### static site JS
- app.js: WIRE_TABLE (AWG→cmil), K_FACTOR, SYSTEMS, setMode(), dropVolts(), calculate(), render{Drop,Size,Length}()
- common.js: COUNTRIES (us/ca presets+code names), window.VDCountry, vdApplyCountry(), 'vd:country' event, mobile Tools menu (clones sidebar links)
- ampacity.js: AMPACITY{cu,al} (310.16), SMALL_CAP (240.4(D)), check()
- conduit.js: THHN_AREA, CONDUIT{emt,pvc40}, fillLimit(n)=53/31/40%, calc()
- boxfill.js: VOL_PER_CONDUCTOR (314.16(B)), BOXES (314.16(A)), calc()
- power.js: SYSTEMS (mult 1/1/√3, usesPF), calc() solves amps/watts/volts
- build.mjs: V (content hashes), stamp(), PAGES[] ({dir, mode?|tool+script+main, title, description})

### comments-app
- CommentsClient.tsx: CommentsClient, CommentCard, nameChoices(), post/remove/saveEdit, PAGE_SIZE 20
- api/feedback/route.ts: GET (paginated, replies ride with parents), POST (name allowlist, link block, 1/hr rate limit, admin-only replies)
- api/feedback/[id]/route.ts: DELETE (admin), PATCH (owner/admin, same content rules)
- lib/auth.ts: authOptions (Google+FB, database sessions, isAdmin via ADMIN_EMAILS)
