Cómo se hacen estas guías

Cada número aquí sale de las mismas tablas de datos verificadas que alimentan nuestras calculadoras — contrastadas con reproducciones textuales del texto del código publicado antes de publicar nada, y selladas para que no puedan cambiar en silencio. Donde nuestras respuestas difieren de las de otro sitio, mostramos los cálculos para que puedas verificar ambas. Estas guías son referencias de planificación, no un sustituto de un electricista con licencia ni de tu código local.
